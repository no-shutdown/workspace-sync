# 候选任务独立存放并转化为新正式任务

---
status: accepted
---

候选任务以独立 Markdown 页面保存在 `<workspace>/wiki/candidates/`，拥有临时身份、来源、理由和关联项目。用户确认后，编译器创建新的正式任务页面和稳定任务 ID，并在候选页面记录“已转化为”关系，同时将候选结果标记为“已转化”；候选页面保留，不覆盖或移动为正式任务页面。被拒绝的候选同样保留并标记为“已拒绝”。

## Consequences

- 候选任务的产生、确认和转化历史可追溯。
- 正式任务目录不会混入未承诺工作。
- 候选任务可以被拒绝、替代或再次讨论而不破坏正式任务身份。

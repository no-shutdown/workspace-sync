# 用一条命令把规划产物编译为开发图谱

---
status: accepted
---

规划工具（例如 superpowers 或 grill-with-docs）完成讨论后，用户只需执行一次知识库编译操作，就能把已有的自由格式原始开发档整理为开发图谱、Wiki 页面、索引和操作日志。当没有原始 Markdown、但当前会话已经形成明确开发任务时，同一操作先从会话中的任务和规划结论生成原始开发档，再继续编译。原始档和编译后的图谱都必须保留。

## Consequences

- 编译操作必须能够识别“已有原始开发档”和“只有当前会话任务”两种输入。
- 规划工具与知识库编译器通过原始开发档或当前会话中的明确任务衔接，不需要共享内部实现。
- 工作空间必须先被选定，编译不能把多个工作空间的背景混在一起。
- 新规划内容应追加为新的原始开发档，不能覆盖此前的原始输入。
- 原始开发档不要求遵循固定模板，信息结构由 LLM 在编译阶段提炼。
- 具体命令的调用表面和会话上下文获取方式仍需单独确定。

# 当前工作空间缺失时默认新建

---
status: accepted
---

当 `compile`、`push` 或其他需要工作空间的操作发现当前 workspace 不存在时，默认进入新建流程并要求用户输入新工作空间名称。系统用该名称初始化 `raw/`、`wiki/`、索引和日志结构，并立即将新 workspace 设为当前工作空间；不自动猜测名称，也不借用其他 workspace。

## Consequences

- 首次开始开发管理时可以直接执行目标操作，不必先执行额外的初始化命令。
- 工作空间名称仍由用户明确决定，避免隐式创建错误的隔离边界。
- 新建流程需要使用与既有 workspace 相同的名称校验规则。

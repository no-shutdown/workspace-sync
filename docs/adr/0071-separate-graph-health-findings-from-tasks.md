# 将图谱健康问题与任务分离

---
status: accepted
---

链接健康检查产生的是图谱结构诊断，而不是开发事实。当前 workspace 的 `wiki/overview.md` 展示这些问题，只有问题首次出现、状态变化或被解决时才追加记录到 `wiki/log.md`；它们不会自动创建正式任务、候选任务或待确认项，只有用户明确确认后才允许进入后续工作流。

## Consequences

- AI 和用户能看到断链、孤立节点等维护问题，但不会被自动制造的任务干扰。
- 健康检查结果可追溯，并可在下一次生成 overview 时重新计算。
- 需要把“图谱维护问题”和“产品/开发缺口”保持为两个不同概念。

# 语义 Wiki 链接限定在当前 workspace

---
status: accepted
---

v1 的开发图谱关系只允许使用指向当前 workspace 节点页面的语义 Wiki 链接。不同 workspace 的 raw、Wiki、索引和日志保持隔离；需要跨迭代参考时，用户可以显式维护普通外部引用，但该引用不参与当前图谱编译、健康检查或默认会话启动上下文。

## Consequences

- 每个 workspace 都能独立编译、检查和理解，不会因其他迭代缺页而产生断链。
- 同一现实对象在不同迭代中可以有各自的局部节点和历史。
- 跨迭代复用信息需要显式复制、总结或引用，而不是隐式共享节点。

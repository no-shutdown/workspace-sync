# 采用 Karpathy 风格的三层知识库，并将开发图谱放入 Wiki 层

---
status: accepted
---

个人开发知识库采用 Karpathy LLM Wiki 的核心分层：原始资料层保存不可覆盖的输入，Wiki 层由 LLM 持续编译和维护结构化 Markdown 页面，Schema 层规定页面、节点、关系和工作流约定；索引和追加式日志用于导航与追踪演化。面向本项目的开发图谱属于 Wiki 层，是该模式在开发管理领域的类型化扩展，而不是另建一套平行知识库。

## Consequences

- 原始开发档必须能独立保存，不能只保留编译后的图谱页面。
- Wiki 页面可以随着新的规划和事实被更新，但原始开发档不因更新 Wiki 而被覆盖。
- Schema 需要同时约束 Karpathy 风格的资料流转和本项目的开发图谱词汇。

# compile 后执行只读链接健康检查

---
status: accepted
---

`compile` 完成 Wiki、图谱关系和生成页面后，通过官方 Obsidian CLI 对当前 workspace 执行未解析链接、孤立页面、无出链页面及相关链接查询。检查只读并将结果报告；只有健康问题首次出现、状态变化或被解决时才追加记录到操作日志。不自动修复人工维护的节点页面，避免编译器静默改变用户意图，同时保留 Obsidian 原生链接分析作为人和 AI 发现图谱问题的共同入口。

## Consequences

- compile 可以在每次增量更新后及时暴露断链或孤立节点，并只记录健康问题的状态变化。
- 人工页面不会因为健康检查被静默重写。
- 生成的 `index.md`、`overview.md` 等页面可由下一次 compile 重建，但检查本身不承担修复职责。

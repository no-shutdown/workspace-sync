# 项目拥有迭代知识库，Workspace 只承载工作现场

---
status: superseded by ADR-0002
---

早期设计曾将迭代知识库视为开发项目内部的项目级状态，而不是某一次 workspace 或对话的状态。该边界后来被修正为“独立的迭代知识库项目”，详见 ADR-0002。

## Considered Options

- **以 workspace 为归属单位**：实现简单，但跨 workspace 接续时必须不断复制和压缩背景，正是当前丢失历史信息的根因。
- **以项目为归属单位（已选择）**：能够让迭代、任务和变更跨会话持续存在；代价是需要定义项目身份及知识库的生命周期。

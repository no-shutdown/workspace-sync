# 记录工作空间涉及的项目分支，但不复制代码

---
status: accepted
---

工作空间需要感知本次开发涉及的多个代码项目，以及每个项目的规范化身份、当前分支和代码提交指针；这些信息作为工作空间项目状态存入个人开发知识库。workspace-sync 不把代码复制进知识库，代码仍由各自的代码仓库管理。

## Consequences

- 一个工作空间可以同时记录多个项目和不同分支。
- AI 新会话可以知道当前开发现场涉及哪些项目以及各自的代码位置。
- 知识库同步的是项目现场元数据，不是代码内容。
- 是否在 pull 时自动切换本地项目分支，需要单独定义恢复策略。

# 使用单一 Git 知识库仓库存放相互隔离的迭代

---
status: accepted
---

个人开发知识库配置一个 Git 仓库链接作为统一存储位置；仓库中的不同文件夹分别代表不同工作空间，也就是不同开发迭代。多个工作空间可以长期并存，但每个工作空间拥有独立的目标、任务、状态、决策和历史，不能因为它们位于同一仓库而自动混合。每次个人或 AI 工作开始前必须明确选择一个工作空间，选择结果决定本次工作的默认读取和写入边界。

## Consequences

- 知识库的操作需要能够明确定位目标工作空间。
- 工作空间文件夹是知识库中的隔离边界，而不仅是组织文件的目录。
- AI 接续开发时必须知道当前会话对应哪个工作空间，避免把其他工作空间的背景当成当前事实。
- 未选择工作空间时，不能把知识库内容作为当前开发背景使用。

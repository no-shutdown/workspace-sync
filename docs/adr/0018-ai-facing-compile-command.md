# 将知识库编译设计为 AI 对话中的一条指令

---
status: accepted
---

知识库编译通过 AI 对话中的 skill 指令执行，例如 `/workspace-sync compile`，而不是要求独立 Shell 进程读取当前对话。指令沿用 `push` 和 `pull` 已建立的当前工作空间，在该工作空间内查找原始开发档；如果没有原始档但当前会话已经形成明确开发任务，则先生成原始开发档，再继续编译开发图谱、Wiki 页面、索引和日志。

## Consequences

- 编译命令可以使用当前会话中已经确认的规划结论作为输入。
- 独立 Shell 工具仍可处理已经落盘的原始档，但不能替代“从当前会话补生成原始档”的 AI 步骤。
- 编译命令必须明确报告它采用了已有原始档，还是从当前会话新生成了原始档。
- 编译不引入新的工作空间参数或选择机制，避免与 `push`/`pull` 的工作空间语义分叉。

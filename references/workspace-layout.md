# workspace 与图谱布局

## 根目录

~~~text
knowledge-base/
├── SCHEMA.md
└── <workspace-folder>/
    ├── 工作区.md
    ├── 原始资料/
    └── 图谱/
        ├── 总览.md
        ├── 索引.md
        ├── 日志.md
        ├── 节点/
        │   ├── 项目/
        │   ├── 系统/
        │   ├── 能力/
        │   ├── 能力缺口/
        │   ├── 任务/
        │   └── 决策/
        ├── 视图/
        │   ├── 系统架构.md
        │   ├── 能力缺口.md
        │   ├── 开发任务.md
        │   └── 系统联调.md
        └── 候选/
~~~

workspace 文件夹是用户可读名称，可以受控改名；workspace 身份以 `工作区.md` 中的稳定 ID 为准。

~~~md

# task-graph

## 归档

尚未归档。
~~~

允许的生命周期：`active`、`paused`、`archived`。完成或放弃一个迭代时归档，不默认物理删除。

## 原始资料

`原始资料/` 只要求文件名以 `.md` 结尾。内容可以是会议笔记、规划稿、问题记录、设计讨论或工具输出，不要求模板。compile 不把原始资料转移到别处，也不覆盖它。

推荐文件名包含日期和中文主题，例如：

~~~text
原始资料/2026-07-27-订单联调规划.md
原始资料/2026-07-28-后续讨论.md
~~~

文件名不是事实身份；节点稳定 ID 和来源引用才是身份依据。

## 节点页面

节点路径和文件名使用中文类型前缀：

~~~text
图谱/节点/系统/系统-订单平台.md
图谱/节点/能力/能力-订单导入.md
图谱/节点/能力缺口/能力缺口-订单导入缺少幂等校验.md
图谱/节点/任务/任务-实现订单导入幂等校验.md
图谱/节点/项目/项目-订单服务.md
~~~

最小 frontmatter：

~~~yaml
---
id: task-xxxx
type: 任务
title: 实现订单导入幂等校验
aliases:
  - task-xxxx
created_at: 2026-07-27T10:00:00+08:00
updated_at: 2026-07-27T10:00:00+08:00
source_refs:
  - ../../../原始资料/2026-07-27-订单联调规划.md
---
~~~

任务节点额外包含 `status`。YAML 不存语义关系；关系放在 Markdown 正文中：

~~~md
## 关系

- 解决：[[能力缺口-订单导入缺少幂等校验]]
- 依赖：[[任务-先完成认证改造]]
- 关联项目：[[项目-订单服务]]
~~~

文件名是可读显示名，不是身份来源。编译器通过 `id` 建立 ID 到页面路径的映射；改名时保留 ID 和 alias，并更新当前 workspace 内的中文 Wiki 链接。同类型同名节点不能自动合并，必要时在文件名后追加稳定 ID 短后缀并生成重复候选。

## 候选页面

候选位于 `图谱/候选/`，例如：

~~~md
---
candidate_id: candidate-task-001
kind: task
status: pending
title: 增加订单导入联调测试
source_refs:
  - ../../原始资料/2026-07-27-订单联调规划.md
---

## 推导理由

由 [[能力缺口-订单导入缺少幂等校验]] 和系统之间的“需要联调”关系推导。

## 决策

待用户确认。
~~~

确认后创建新的正式任务页；候选页不改成正式任务页，不复用候选 ID。

## 生成页面

- `图谱/总览.md`：面向人和新 AI 的当前接手视图，可重建。
- `图谱/索引.md`：按节点类型的完整目录，可重建。
- `图谱/视图/系统架构.md`：系统层级和能力视图，可重建。
- `图谱/视图/能力缺口.md`：缺口到任务的解决视图，可重建。
- `图谱/视图/开发任务.md`：任务树和依赖视图，可重建。
- `图谱/视图/系统联调.md`：系统联调关系视图，可重建。
- `图谱/日志.md`：操作、输入、输出、冲突、项目采集和健康问题状态变化的追加审计日志。

生成页面不承载独立事实；人工修改进入原始资料或具体节点页面。

## 隔离规则

语义 Wiki 链接必须指向同一 workspace 内的正式节点。跨 workspace 引用不参与 compile、图谱关系或健康检查；如用户需要，可以在正文写普通外部引用并明确路径，但不能隐式共享节点。
